# DQ01

A logo intro for deadquiet42, made from code in under 4kb.

[Run it](https://deadquiet42.github.io/dq01/), or open `dq01.html` in a browser and click. It plays full screen with sound.

## Build

```
npm install
npm run build
```

`dq01-source.js` is the readable source. The build minifies it with terser and packs it with roadroller into `dq01.html`.
